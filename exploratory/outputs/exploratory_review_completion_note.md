## Gaps and ambiguities

### Task 3 ("core visual suite") — two of five items since filled by a follow-up task
The task brief described this as covering "haul map, temporal coverage, composition/
big-shoal figures, H1 residual map, reframed H2/H3 strategy exploration." A repo-wide
search (all `pipeline/*.R` and `pipeline/R/*.R` scripts, `outputs/figures/`, `outputs/`,
`gis/`, `supplementary/`, `H1_results/`, and every `display_discussion/*.md` doc) found:

- **Haul map** (a spatial map of survey haul locations) — **not found anywhere on disk**
  at the time of the original collation. No script in `pipeline/` produced a haul-location
  or haul-count map; `gis/ns_ibts_hauls_2000_2020.gpkg` is a raw GIS data file, not a
  rendered figure. **Since filled**: a follow-up task ("Missing Visuals — Haul Map &
  Composition Figures") produced `haul_map_1` — a choropleth of total haul count per ICES
  rectangle (1985-2015), with the 32 no-Couce-coverage rectangles outlined — using the
  already-existing `gis/ICES_rectangles/ICES_Statistical_Rectangles_Eco.shp` shapefile
  (via `load_ices_rectangles_sf()`, already in use elsewhere in the H2/H3 pipeline) and
  the already-computed `h3_pre_rectangle_usability_flags.csv`. No new shapefile was needed.
- **Temporal coverage** — no standalone figure exists distinct from Task 1's A.1 (haul
  count per year) and A.2 (rectangle x year heatmap), which are already indexed under
  Task 1. Not addressed by the follow-up task (out of its scope) — still a gap.
- **Composition / big-shoal figures** — the *ratio-overlay* versions
  (`h1_dominance_ratio_vs_D.png`, `h1_dominance_ratio_vs_sizeCV.png`) are already indexed
  under Task 2 (dominance figures) and are not duplicated here. **Since filled**: the
  follow-up task confirmed these are not the same as the *plain* composition distributions
  the brief asked for, and produced `composition_1` (S/D/size_CV histograms), `composition_2`
  (plain D vs size_CV scatter, no ratio colouring), and `composition_3` (big-shoal reference-share
  summary). No formal combined D x size_CV "big shoal" cutoff was found anywhere in the H1
  dominance analysis (`explore_h1_haul_dominance.R` and `display_discussion/*.md` treat top-decile-D
  and bottom-decile-size_CV as separate marginal extremes only, never combined); per the
  follow-up brief's fallback, `composition_3` reuses the pre-existing D top-decile boundary
  from `h1_dominance_by_D_bins.csv` (D >= 0.9006, n=1,206) as a labelled reference line only,
  not a new formal classification.
- **H1 residual map** (a haul-level, H1-specific spatial residual map) — **not found**, and
  explicitly deferred by the follow-up task (it addressed only the haul map and composition
  figures, not the H2/H1 residual map). The only residual maps that exist are (a)
  `h3_pre_C2_residual_maps_by_decade.png` / `h3_pre_C3_residual_slope_map.png` (already
  indexed under Task 1 — decade/slope maps, not "the H1 residual map"), and (b)
  `h2_map_abs_residual.png`, a **rectangle-level H2** map generated by the core confirmatory
  H2 pipeline — not haul-level, and not one of the four scoped source tasks. Excluded from
  the collation rather than guessed into this row. Still a gap.
- **"Reframed H2/H3 strategy exploration"** — no distinctly-named script, doc, or figure
  set matches this description beyond Task 1 (pre-H3 feasibility) and Task 4 (policy-zone
  feasibility) themselves, both of which are literally exercises in reframing the H2/H3
  strategy and are already fully indexed as Tasks 1 and 4. Most plausible reading: this
  brief item refers to those two tasks, not a separate fifth output set. Still a gap (by
  this reading, not something to separately fill).

**Net result: Task 3 now contributes 4 figures + 1 run log to this index** (haul map,
composition_1/2/3); the H1 residual map, standalone temporal coverage, and "reframed
strategy exploration" items remain gaps as described above.

### Null-model figure captions (Task 2) — resolved
`h1_null_r2_uniform_log_b95.png` and `h1_null_r2_b_shuffle.png` are captioned by their
generating code as "Null distribution of R² (log scale): primary: {method}" or
"... robustness: {method}". This was initially left ambiguous (which of the two schemes
is "primary" is decided at runtime from the shape of the log(B_obs) distribution), but was
resolved by reading the already-saved `outputs/null_sampling_decision.rds` (a read of an
existing artifact, not a recomputation): `primary_method = "uniform_log_b_95"`,
`robustness_method = "b_shuffle"` (distribution is peaked). `index.md` has been updated
accordingly.
